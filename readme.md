# ChatBot Gemini

Este proyecto consiste en un bot creado en Python que emplea la API de Gemini para analizar y responder mensajes de forma inteligente.

## Funcionalidades

- Conexión con la API de Gemini.
- Procesamiento de lenguaje natural.
- Configuración y ampliación sencillas.
- Respuestas automáticas impulsadas por IA.

## Requisitos

- Python 3.8 o superior
- `requests`
- Clave de API de Gemini

## Instalación

```bash
git clone https://github.com/CInthiaAcosta/tp3ChatBot.git
cd tp3ChatBot
pip install -r requirements.txt
```

## Uso

1. Ingresa tu clave de API en el archivo de configuración.
2. Inicia el bot con:

```bash
python main.py
```

## Configuración

Modifica el archivo `config.py` para incluir tu clave de API y otros parámetros necesarios.
